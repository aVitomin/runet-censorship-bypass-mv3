# Установка, обновление и удаление

Текущий опубликованный продукт предназначен для браузеров на Chromium и
проверяется в Google Chrome Stable. Firefox не входит в этот выпуск. Установка
выполняется вручную из распакованного ZIP: версии в магазине и автоматических
обновлений сейчас нет.

Последний опубликованный стабильный выпуск —
[`v0.0.3.0`](https://github.com/aVitomin/runet-censorship-bypass-mv3/releases/tag/v0.0.3.0).
Текущая документация и скриншоты соответствуют интерфейсу этого выпуска.

## Скачать стабильный выпуск

1. Откройте [страницу `v0.0.3.0`](https://github.com/aVitomin/runet-censorship-bypass-mv3/releases/tag/v0.0.3.0).
2. Скачайте
   [`runet-censorship-bypass-mv3-0.0.3.0-cd59e14.zip`](https://github.com/aVitomin/runet-censorship-bypass-mv3/releases/download/v0.0.3.0/runet-censorship-bypass-mv3-0.0.3.0-cd59e14.zip).
3. При желании скачайте рядом
   [`runet-censorship-bypass-mv3-0.0.3.0-cd59e14.sha256.txt`](https://github.com/aVitomin/runet-censorship-bypass-mv3/releases/download/v0.0.3.0/runet-censorship-bypass-mv3-0.0.3.0-cd59e14.sha256.txt).

Не скачивайте исходный код из автоматически созданных ссылок **Source code**:
это не готовое расширение.

## Проверить SHA-256

Ожидаемый SHA-256 ZIP:

```text
68a32aa9162d5ba8b2cd9070c2eba6e5eb055434b899c284107c55d3e5a55635
```

В PowerShell:

```powershell
Get-FileHash .\runet-censorship-bypass-mv3-0.0.3.0-cd59e14.zip -Algorithm SHA256
```

Результат должен точно совпасть с опубликованным значением и файлом
`*.sha256.txt`. Если значение отличается, не устанавливайте архив: удалите его
и скачайте снова со страницы выпуска.

## Распаковать в постоянную папку

1. Создайте постоянную папку, например внутри каталога документов или
   приложений пользователя.
2. Полностью распакуйте ZIP в неё.
3. Найдите каталог, в корне которого лежит `manifest.json`.

Не оставляйте расширение в каталоге временных загрузок и не перемещайте или не
удаляйте папку после установки. Chromium загружает распакованное расширение
прямо из этих файлов; если папка исчезнет, расширение перестанет загружаться.

## Загрузить в Chromium

1. Откройте `chrome://extensions`. В другом Chromium-браузере используйте его
   собственную страницу управления расширениями.
2. Включите **Режим разработчика / Developer mode**.
3. Нажмите **Загрузить распакованное расширение / Load unpacked**.
4. Выберите именно папку, в которой непосредственно находится `manifest.json`.
5. Закрепите значок Runet Censorship Bypass на панели инструментов, если хотите
   быстро менять маршрут текущего сайта.

Нельзя выбрать ZIP, внешний каталог с ещё одной вложенной папкой или корень
репозитория. Ошибка **Manifest file is missing or unreadable** обычно означает,
что выбран каталог на один уровень выше или ниже.

## Первая настройка

При первом открытии popup расширение показывает, что настройка не завершена, и
предлагает открыть Options:

1. В **Automatic routing** выберите встроенный источник или **Manual rules
   only**.
2. При необходимости настройте **Proxy connections**, если вы планируете явные
   правила Proxy.
3. Нажмите глобальную кнопку **Apply configuration**.
4. После успешного применения используйте popup для ежедневного выбора
   **Auto**, **Proxy** или **Direct**.

Настройка Proxy connections необязательна для источника, который может работать
без локальных или пользовательских прокси. Сохранение полей не заменяет Apply.
Подробности — в [руководстве пользователя](USER_GUIDE.md).

## Обновить распакованную установку

Автоматического обновления из магазина нет. Для каждого нового выпуска:

1. Скачайте новый ZIP только со страницы
   [Releases](https://github.com/aVitomin/runet-censorship-bypass-mv3/releases).
2. Проверьте его опубликованную SHA-256.
3. Закройте Options и popup.
4. Распакуйте новый выпуск в отдельную постоянную папку.
5. Откройте страницу расширений и выберите один из безопасных способов:
   - удалите старую карточку и загрузите новую папку через **Load unpacked**;
   - либо замените содержимое текущей папки целиком и нажмите **Reload**, если
     точно сохранили путь и не смешали версии.
6. Откройте **About** и проверьте версию `0.0.3.00`, затем проверьте Overview и
   снова примените конфигурацию только если интерфейс этого требует.
7. Старую папку удаляйте лишь после успешного запуска новой версии.

Не объединяйте файлы двух выпусков и не копируйте поверх них исходники из
репозитория. Настройки обычно сохраняются в профиле браузера, но перед важным
обновлением полезно записать несекретные параметры. Не экспортируйте и не
публикуйте пароли или приватные proxy/source URL.

## Удалить

1. При доступном управлении нажмите **Turn off extension proxy**, чтобы вернуть
   Chromium к системной конфигурации прокси.
2. Откройте страницу управления расширениями.
3. Нажмите **Удалить / Remove** на карточке Runet Censorship Bypass.
4. После удаления карточки можно удалить постоянную папку с файлами расширения.

Если интерфейс показывает, что прокси контролирует другое расширение или
политика, Runet Censorship Bypass не может очистить чужую настройку. Сначала
разберитесь с владельцем в браузере или у администратора.

## Если установка не работает

- **Manifest file is missing or unreadable** — выберите папку с
  `manifest.json` в корне.
- Карточка появилась, но popup не открывается — нажмите **Reload** и убедитесь,
  что постоянная папка не перемещена.
- Chromium сообщает об ошибке файла — заново скачайте ZIP, проверьте SHA-256 и
  полностью распакуйте его.
- Настройка не завершена — откройте Options, выберите Automatic routing source и
  нажмите **Apply configuration**.

Больше сценариев: [решение проблем](TROUBLESHOOTING.md). Не прикладывайте к
публичному issue локальные пути профиля, пароли, приватные endpoints, исходный
PAC или историю посещений.
