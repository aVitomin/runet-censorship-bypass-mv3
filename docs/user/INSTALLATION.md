# Установка ограниченной beta

Текущий MV3-выпуск устанавливается вручную из ZIP-архива на GitHub. Это не
магазинная установка и она не обновляется автоматически.

## Скачать выпуск

1. Откройте [текущий публичный prerelease `v0.0.2.0-beta2`](https://github.com/aVitomin/runet-censorship-bypass-mv3/releases/tag/v0.0.2.0-beta2).
2. В блоке **Assets** скачайте ZIP расширения и соответствующий файл
   `*.sha256.txt`. Точные имена и опубликованный SHA-256 также приведены в
   [блоке текущего выпуска](../../README.md#текущий-выпуск).

Не используйте автоматически созданные GitHub архивы **Source code**, если вам
нужна готовая сборка расширения.

## Проверить SHA-256

Проверка не обязательна для загрузки, но подтверждает, что архив не изменился.

Windows PowerShell:

```powershell
Get-FileHash .\runet-censorship-bypass-mv3-*.zip -Algorithm SHA256
Get-Content .\runet-censorship-bypass-mv3-*.sha256.txt
```

Linux:

```bash
sha256sum runet-censorship-bypass-mv3-*.zip
cat runet-censorship-bypass-mv3-*.sha256.txt
```

macOS:

```bash
shasum -a 256 runet-censorship-bypass-mv3-*.zip
cat runet-censorship-bypass-mv3-*.sha256.txt
```

Сравните 64 шестнадцатеричных символа без учёта регистра. Не продолжайте, если
значения различаются.

## Распаковать и загрузить

1. Распакуйте ZIP в постоянную папку. Не запускайте расширение из временной
   папки загрузок, которую может очистить система.
2. Убедитесь, что в выбранной папке непосредственно находится `manifest.json`.
3. В Brave откройте `brave://extensions`; в Chrome — `chrome://extensions`.
4. Включите **Developer mode / Режим разработчика**.
5. Нажмите **Load unpacked / Загрузить распакованное расширение**.
6. Выберите папку с `manifest.json`.
7. Закрепите значок расширения на панели, если он скрыт в меню расширений.

Нельзя выбирать ZIP напрямую. Если `manifest.json` находится ещё на один
уровень глубже, выбрана не та папка.

## Обновить распакованную beta

Ручное обновление лучше выполнять в той же постоянной папке: путь может влиять
на идентификатор распакованного расширения и доступ к ранее сохранённым
настройкам.

1. В popup нажмите **Turn off extension proxy**.
2. Скачайте новый ZIP и проверьте его хэш.
3. Распакуйте новый архив отдельно и убедитесь, что его корень содержит
   `manifest.json`.
4. Закройте открытые страницы popup/options. Замените содержимое постоянной
   папки полным содержимым нового архива; не оставляйте удалённые файлы старой
   версии.
5. На странице расширений нажмите **Reload / Обновить** на карточке расширения.
6. Откройте настройки, проверьте источник и методы прокси, затем явно нажмите
   **Apply configuration**.

Загрузка из новой папки может выглядеть для Chromium как чистая установка. Не
удаляйте старую карточку до проверки, если важно сохранить текущий профиль.

## Удалить

1. Сначала нажмите **Turn off extension proxy** и убедитесь, что статус стал
   `OFF`.
2. Откройте страницу расширений и нажмите **Remove / Удалить**.
3. При желании удалите папку распакованного архива вручную.

Если показан `EXT`, прокси контролирует не это расширение. Найдите другое
расширение или политику, прежде чем менять системные настройки.

## Частые ошибки установки

### «Manifest file is missing or unreadable»

Выбран ZIP, внешняя папка или неполностью распакованный архив. Выберите каталог,
в котором виден `manifest.json`.

### «Invalid value for …» или другая ошибка manifest

Проверьте хэш, удалите неполную распаковку и извлеките архив заново. Не меняйте
`manifest.json` вручную.

### Расширение загрузилось, но постоянно показывает ожидание

Нажмите **Reload** на странице расширений и откройте popup снова. Если проблема
повторяется, перейдите к [решению проблем](TROUBLESHOOTING.md#расширение-постоянно-загружается).

### Отличие от установки из магазина

Распакованная beta показывает режим разработчика, не получает автоматические
обновления и требует сохранить каталог на диске. Этот форк пока не заявляет
текущий MV3-пакет как опубликованный в Chrome Web Store, Edge Add-ons или
Firefox Add-ons.

Следующий шаг: [руководство пользователя](USER_GUIDE.md).
